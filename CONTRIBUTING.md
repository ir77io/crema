# Contributing to Crema

Crema is a GPL-3.0 fork of [Crema](https://github.com/ir77io/crema). Open an issue before large changes.

## Build
```bash
xcodebuild -project Crema.xcodeproj -scheme Crema -destination "platform=macOS" build
```

Requires Xcode and macOS 14+. By contributing you agree your work is licensed under GPL-3.0.
